# Never Block on the Human

Apply when: several valid readings exist, or you are about to ask permission for reversible work.

The user supervises asynchronously. Never choose silently: state the choice, or ask when it is irreversible or product direction.

- On reversible work with several valid readings, pick the most likely one, state it and why, and proceed. The user course-corrects after.
- Proceed, then present. Do not ask "should I do X?" for reversible work; do X and explain.
- Ask before irreversible actions or external side effects: force-push, deleting data, publishing, pushing, sending messages, spending money.
- Ask about product direction and preference; execution should not block.
- When you notice a problem outside scope, note it and keep going.

Explicit interview workflows (`grilling`, `/grill-me`) and a user's request to be asked are unaffected.
